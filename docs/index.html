BAD Molecule Filter

Predicts whether a small molecule forms colloidal aggregates in a biochemical assay.

Get the tool

Open source, GPL-3.0. A hosted version is being set up; until then it runs locally in three commands.

What it does

Colloidal aggregation is the most common reason a compound looks active in a biochemical screen without touching its target. This tool takes SMILES and returns a probability that each compound aggregates, using an extremely randomised trees model over Morgan fingerprints and Mordred descriptors, trained on detergent counter-screen data.

Reading the output

ProbabilityCall
> 0.6Aggregator
0.3 to 0.6Ambiguous. Treat as untested rather than clean.
< 0.3Non-aggregator

A negative call means the model saw nothing resembling an aggregator, not that the compound was tested and found inert. The training labels come from assay behaviour, so a compound simply inactive against the screening enzyme is indistinguishable from one measured and found not to form colloids.

Cite

Abou Hajal A, Bryce RA, Amor B, Atatreh N. Boosting the Accuracy and Chemical Space Coverage of the Detection of Small Colloidal Aggregating Molecules. J Chem Inf Model 2024. 10.1021/acs.jcim.4c00363

Run it locally

If you need batch scoring, or want it to keep working whatever happens to this page:

git clone https://github.com/AbdallahHajal/BAD-Molecule-Filter
cd BAD-Molecule-Filter
pip install -r requirements.txt
python app.py
