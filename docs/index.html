A negative call means only that the model saw nothing resembling an aggregator. It does not mean the compound was tested and found inert. The training labels come from assay behaviour, so a compound simply inactive against the screening enzyme is indistinguishable from one measured and found not to form colloids.

What it does

Colloidal aggregation is the most common reason a compound looks active in a biochemical screen without touching its target. Each structure is turned into 602 Morgan fingerprint bits and 255 Mordred descriptors, and scored by an extremely randomised trees model of 1000 trees trained on detergent counter-screen data.

Run it on your own machine

For large batches, or to keep it working whatever happens to this page:

git clone https://github.com/AbdallahHajal/BAD-Molecule-Filter
cd BAD-Molecule-Filter
pip install -r requirements.txt
python server.py

That opens the same page at http://localhost:7860 and scores compounds locally. The model file is downloaded once on first run and cached.
